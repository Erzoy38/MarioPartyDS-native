Dieses Paket enthält das Programm, aber nicht das Spiel selbst. Jeder Spieler braucht seine eigene
ROM-Datei von Mario Party DS (Europa, Rev 1, Datei mit der Endung .nds). Die ROM gehört nicht in
dieses Paket und wird nicht weitergegeben.

Inhalt
------
MarioPartyDS.exe          das Spiel
SDL3.dll                  Fenster, Ton und Controller (gehört neben die Exe)
MarioPartyDS-server.exe   der Server, nur für den Host einer Online-Partie
ONLINE.txt                Anleitung für das Spielen über das Internet
LIZENZ.txt                Urheberrecht und was erlaubt ist
SDL3-LICENSE.txt          Lizenz von SDL3
textures\                 Ordner für Texturpakete, mit Anleitung

Weitergeben
-----------
Nur die ZIP-Datei weitergeben, nicht den eigenen Ordner. Wer den Server einmal gestartet hat, hat
dort die Datei MarioPartyDS-server.key: der geheime Schlüssel des Servers. Mit ihr könnte sich ein
anderer als dieser Server ausgeben. Sie bleibt beim Host.

Erster Start
------------
1. Den Ordner irgendwohin entpacken, zum Beispiel auf den Desktop.
2. MarioPartyDS.exe starten. Es erscheint der Startbildschirm. „SELECT ROM IMAGE“ fragt einmal nach
   der ROM-Datei und startet dann das Spiel; danach heißt der Punkt „START GAME“.
3. Windows zeigt bei unbekannten Programmen eventuell „Der Computer wurde durch Windows geschützt“.
   Dann „Weitere Informationen“ und „Trotzdem ausführen“ wählen, wenn das Paket vom Host stammt.
4. Unter „SETTINGS“:
   PRELAUNCH  Sprache des Spiels
   VIDEO      Auflösung (alle Auflösungen des Bildschirms), Vollbild, Anordnung der beiden
              Bildschirme (übereinander, nebeneinander, Hybrid), Bildformat (4:3, 16:9, Widescreen),
              3D-Auflösung (1x bis 4x, schärfere 3D-Grafik)
   MODS       Texturpakete (HD-Texturen), siehe textures\LIESMICH.txt
   ONLINE     eigener Name und die Server-Adresse, die der Host nennt

Spielstand, Einstellungen und Protokoll liegen unter %APPDATA%\MarioPartyDS\MarioPartyDS\.

Tasten
------
Pfeiltasten       Steuerkreuz
X / Z             A / B
S / A             X / Y
Q / W             L / R
Enter             Start
Umschalt rechts   Select
Maus              Touchscreen (unterer Bildschirm, linke Maustaste)
Leertaste         ins Mikrofon pusten
F10               Fenstergröße
F11               Vollbild
Esc               Zurück zum Startbildschirm

Controller (wird erkannt, sobald er angeschlossen ist): Tasten wie beim DS (A rechts, B unten,
X oben, Y links), Schultertasten L/R, Start, Back = Select. Der rechte Stick bewegt einen Zeiger
auf dem Touchscreen; Drücken des rechten Sticks oder der rechte Trigger tippt. Linker Trigger: ins Mikrofon pusten.
